## 本研修のねらい

ソーシャルゲーム（運営型モバイルゲーム）の開発・運用では、毎週のイベント更新、ガチャ施策、課金決済、OSアップデート対応など、短期間で高品質なリリースを継続することが求められます。  
本資料では、国際標準のテスト知識体系（ISTQB® Foundation Level V4.0）の全6章を、ソーシャルゲーム開発の現場に置き換えて体系的に学びます。

## 研修ふりかえり：実務で意識すべき5つの行動指針

1. **「動かす前」にバグを潰す**

   企画書やマスタデータCSVの段階で疑問を挙げ、シフトレフトを実践する。

2. **「仕様通り」の先を見る**

   検証だけでなく、プレイヤーが楽しく安心して遊べるか（妥当性確認）を常に問う。

3. **リスクと技法でメリハリをつける**

   全数テストは不可能。課金・確率・データ保全などの高リスク領域に技法と工数を集中する。

4. **再現できる明確な報告をする**

   エンジニアを責めず、環境・手順・期待結果と実際結果を整理して建設的に伝える。

5. **チーム全員で品質を作る**

   QAだけでなくプランナー・エンジニアと対話し、イベントごとのふりかえりで仕組みを改善し続ける。
